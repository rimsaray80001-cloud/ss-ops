Browser Compatibility & Permission Troubleshooting

If you open the dashboard on another browser or device and the data does not sync correctly, please check the following:

  • Browser-Specific Settings (localStorage): Since configuration is stored locally inside each browser's sandbox, another browser will start in offline/local-only mode. Use the Share Settings Link above to quickly share and apply your configuration to other browsers.
  • Google Account Multi-Login Bug: If you are logged into multiple Google accounts in the other browser, Google's server may return authentication errors (401/403 or CORS redirects). Try using an Incognito window, a separate browser profile with only one active Google account, or logging out of other Google accounts.
  • Apps Script Permission: Ensure your Google Apps Script is deployed exactly with:
    • Execute as: Me (your email)
    • Who has access: Anyone (not "Only myself" or "Anyone with Google account").
    If you changed these, deploy a new version and update the Web App URL.
  • Strict Privacy/Tracking Shields: Brave Shields, Safari cross-site tracking prevention, or Firefox strict privacy mode may occasionally block requests to Google domains. If so, add an exception or allow cross-site tracking/cookies for this site.
